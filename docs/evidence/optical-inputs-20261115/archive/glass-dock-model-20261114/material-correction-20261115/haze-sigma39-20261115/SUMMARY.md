# Dock 基础磨砂：σ3.9 单变量校准

同一保存 APK、h=.72、tone/rim/Q/几何不变，四公开 shape/control 对共 8 REST。新结果/PNG 读取前冻结方法，17 项检查通过；沿用 ICC、真实 support/core、16,778px 内部场、全部 62 深度区间和原五阈值。只检验固定尺寸浅色静态校准，不验收不同尺寸、完整动作或逐帧动态。

**事前预测的弱尾缩短、核心增强方向成立，但边缘仍有回归，不改变默认值。** σ3.9 的三角形条件响应更接近此次 C 参考；这不能反推原生 σ 或证明完整材质一致。

## 必须保留的边缘残差

四 shape 的全基础、depth≥32、depth0–4 区域 RGB/Y′ MAE 均改善或持平，但三角形最外 **depth[0,1) 的 1,496px 明确退步**：相比 σ15.6，RGB/Y′ MAE 增量为 `+.228610/+.135027/+.070856/+.018657`。其余 61 深度层改善；另三个 shape 的全部 62 层改善或持平。这一层不能被合并后的 edge0–4 改善掩盖，也不能据此推断厚度或高光成因。

端点计数同样未被隐藏：三角形真实 support 内 σ3.9 shape 的 RGB=255 为 `135/0/301px`，core 为 `125/0/292px`；C 原生分别为 `139/4/290px`、`122/4/272px`。两者 control 全为 0，native REST/repeat 相同。端点数量接近不能证明位置或未截断振幅一致；更强 core 也不能全部解释为未饱和增益。
