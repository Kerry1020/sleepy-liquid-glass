# 固定 dark rim 三系数结构检查

这组三系数能够生成正、负边缘响应，但不能同时重现已公开原生灰阶与彩色响应。当前固定家族应视为有明显结构残差的诊断模型，不能据此声明 dark rim 已对齐。

只读取公开 M/N 的 manifest、已通过的 native index、既有 native top curves，并核对原 PNG 字节哈希；没有解码新图。实际 `effective_bar_theme=dark` 的 15 个 session 合成 13 个完整 RGB 分组。M/N 的 gray77、gray128 曲线逐值相同，各计一个分组。gray0/26/36/51/77/102/128/153/179/204 与 red/green/blue 全部包含；请求 dark 的 gray230 实际 bar 为 light，因此排除。

每个原生场景扣除自身 `x375,y1174..1183` 十行 RGB 均值，保留其 min/max 与所有残差。模型保持 `width=1.2dp` 的有限半余弦，恰好覆盖 y1168、1169 两个像素中心；仅三个 signed 系数：`e0 + e1*Y + e2*(c-Y)`。body、width、位置、颜色分组、角向响应均不拟合。沿用原来未截断 RGB 目标与 0/255 单侧区间约束，重复帧不用作独立训练样本。留出时同时移除该 RGB 的全部通道、全部行和重复 packet。

| 指标（RGB code） | 全部 13 组拟合 | 整 RGB 分组留出 |
|---|---:|---:|
| 两行有效 rim MAE | 7.2001 | 8.0714 |
| 全 16 行 MAE | 1.0273 | 1.1362 |
| 最大绝对误差 | 31.5431 | 33.6933 |
| 明显正负方向错误 | 4 | 4 |

全 16 行结果受另外 14 行零 rim 支撑稀释；应同时看首两行。无 rim 基线首两行 MAE 为 27.7077，说明增加 rim 有帮助，但改善幅度不能等同于对齐。截断区间可行只代表保留 0/255 的单侧限制，不能代表其他颜色已拟合。

全拟合系数为 `e0=27.7527479 code, e1=0.0916211/code, e2=0.3319198/code`。以下响应均为扣自身 body 后、模型执行最终 clip 后的数值：

| 未截断可观察通道 | 原生第 1 / 2 行 | 模型第 1 / 2 行 |
|---|---:|---:|
| red G/B | −10.000 / −7.000 | +21.543 / +12.639 |
| green G | +21.200 / +12.200 | +31.200 / +31.200 |
| blue R/G | +16.800 / +9.800 | +27.421 / +16.088 |

无法表达的地方有明确的同一家族代数证据：用同样三个系数精确匹配 gray0、gray179、red G 的第 1 行信号，green G 的预测 preclip 增量会成为 +129.535，执行 clip 后仍为 +31.200，原生仅 +21.200；gray204 会被预测为 +63.469，原生为 +49.000。这不是再加拟合参数，而是同一三维线性特征空间中三条方程的唯一解检查。它说明三系数无法把这几个未截断观测同时精确重现。

灰阶自身也限制了这个家族：灰色 `c-Y=0`，所以同一边缘行只能随输入灰度呈仿射变化；原生第 1 行从 gray0 的 +27 增到 gray179 的 +59，再降至 gray204 的 +49，单一仿射函数无法表达这个转折。固定宽度还使未截断通道共享两行比例；这轮没有拟合额外形状或宽度。

全部分组、每行 RGB signed 残差、留出系数和原图哈希见 `signed-three-coeff-report.json` 与 `signed-three-coeff-method.json`。本轮仅为同尺寸、直线顶边的公开静态校准结构检查；不包含 N2、heldout、noise、其他尺寸、完整动作、设备采集或 runtime 修改。
