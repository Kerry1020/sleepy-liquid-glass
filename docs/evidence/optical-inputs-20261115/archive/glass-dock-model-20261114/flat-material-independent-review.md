# 平坦材质校准：独立数值复核

本轮校准数据的 CSV 算术一致，材质响应仍明显不匹配。未修改冻结分析方法，未读取 N/holdout。复核程序为 `review_flat_material.py`，完整数值在 `flat-material-independent-review-r2.json`。

## 复核结果

- 独立重写同一名义胶囊的距离表达式与 selected/glyph 排除，得到 base **47,286**、depth≥32 内部 **16,778** 像素，与冻结方法一致。ICC 解码后直接复算 5 灰 × 2 请求主题、两系统的 RGB/Yprime、分位数和 Android−native MAE/RMSE：**1,360 项 CSV 对照差为 0**。
- 从 RGB 均值重算 256 项 Yprime 均值，最大差 **1.14×10⁻¹³**；62 个固定深度 bin 按像素数重聚合 512 项 base 均值，最大差同为 **1.14×10⁻¹³**。没有用均值之差冒充 MAE。
- 第一轮独立程序的矩阵乘法出现浮点 warning，输出仍有限且一致；R2 改成显式 RGB 乘加、加入 finite 断言后无 warning，结论相同。首轮结果保留，冻结分析器未动。

最明显的两组是 **depth≥32 固定内部区域 Yprime 均值**，不是某个中心像素：

| 输入 / 请求主题 | native 实际栏主题 | native 均值 | Android 均值 | 同像素 Yprime MAE |
| --- | --- | ---: | ---: | ---: |
| gray26 / light | light | 47.0693 | 185.5783 | 146.6423 |
| gray230 / dark | light | 235.1834 | 118.2254 | 127.6657 |

这不能靠一个固定 tint/alpha 的简单调整统一解决：light 的 gray128 中心仅差 3，顶缘却差 142；gray26 中心相反差 153。五个等间隔 gray 输入的 native light 中心增量为 140、22、22、27，不符合固定 sRGB code-space over 叠色的单一斜率。该观察只否定这个简化模型，不反推原生使用了哪一种唯一物理/私有材质实现。

## 重复与桥接的限制

16 场景 base/interior 的 128 条 native REST−REPEAT 误差记录均为 0；独立解码的 10 个灰阶场景 REST/REPEAT 全帧也逐像素相同。**这不是新的独立样本，不提供采样方差或泛化证明。**

新 gray128 与 C 旧 gray128 的 native 原图，在两请求主题、REST/REPEAT 的 base、内部及上述 ROI raw 差异均为 0；1024 条桥接 CSV 记录也全为 0。这只说明这些已登记像素相同。C 当时未冻结完整 debug.dylib/whole-bundle 字节身份，历史 fullbinary 一致性仍不可追认。

固定排除区域仍可能包含模糊前景影响；内部均值不能当作纯材质常数。五灰三色只是当前校准输入，不能据此声称静态验收、动态/多尺寸覆盖、99.99% 相似度或唯一厚度/折射率模型。
