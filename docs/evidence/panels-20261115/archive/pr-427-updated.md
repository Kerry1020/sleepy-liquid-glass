## 本轮变化

- 新建操作立即进入独立编辑路由，目标页首帧后由 ViewModel 初始化记录；不再把未提交记录的小组件刷新放在导航前。编辑页等到目标记录进入已发布数据后再呈现内容。
- 离场管理页保留最后可见列表，避免新卡片抢在导航动画前出现。初始化返回等待插入和清理完成，保存按请求协调并只交付一次返回；保留原选择、默认表和既有调休子页入口。
- 关于页以既有开源地址为基准，Liquid Glass 的开源地址、隐私政策、开源声明共用同一行式卡片与右侧玻璃外链按钮，统一图标、间距、圆角、触达区和背板采样。隐私独有的大胶囊已移除；Material Design 原布局保留，开源地址的下划线文字补齐真实链接。
- Liquid Glass 日期复用公开 Material title/headline 和官方输入 body；输入代理固定为 Input，日历与年份 body 用公开 M3 组成互斥绘制，避免透明年份面板叠加日历，不加不透明罩。Material Design / 无玻璃宿主仍直接使用官方完整日期选择器。
- 作息编辑保存和复制完成使用独立回调；新建未保存来源在复制成功后清理，副本保留并返回管理列表。编辑非当前课表时按目标 ID 读取课程数量和策略原始基线；目标数据的 StateFlow 按 ID 缓存，供子页返回首帧复用。
