# 彩虹竖条弯曲：最小冻结诊断

**仅准备，像素解码 0，未执行、未通过。** 只复用已经观察过的 `color_stripes`
历史原图，先做 light Alert，随后按同一方法报告已登记的 dark Alert 和 light/dark
Sheet；不增加背景、控件、尺寸、动态、新采集或参数拟合。当前 Android 对照是
`panels-alert-floor-budget-history-r2-20261115` 的 mixed/unaccepted 源码候选，
不是已验收版本。5 个当前 runtime 源码哈希与该采集 plan 相符；原始安装 APK 哈希、
原生会话、矩阵、已分析文件和原图字节哈希详见 `source-index.json`。旧 baseline 单列。

目标是 **apparent colored contour（表观彩色边界）**：测固定已知边界的 `x50(y)`，
相对中心段的偏移 `Δx(y)`，左侧向左/右侧向右的有符号外偏、倾斜与曲率。它受颜色、
模糊、覆盖、高光、周期重复和多像影响，不能命名为真实光线位移、唯一二维映射或厚度。

支持在看像素之前固定：源为 18pt 宽的六色竖条，世界原点0、375×667、@2。
主边界 `x=54、324pt`，辅边界 `x=72、306pt`；各自使用自身相邻源色向量，不强制镜像
或假定两边源色相同。扫描为 `[x−9,x+9)` 的原始0.5pt像素中心；平台为
`[x−9,x−1)` 与 `[x+1,x+9)`。边界走出支持、无法唯一辨认或平台被过渡污染时保留失败，
不移动窗口、不换颜色、不追最近峰。Alert 所有行取 `[257.5,429.5)`，Sheet 所有行取
`[317.5,659)`；原生 Sheet AX 顶317.7独立保留，不拟合到317.5。上下各24pt单列。
中心参照固定 Alert `[350,359)`、Sheet `[499.5,507.5)`，来自既有协议/AX空隙；
其所有行均须独立合格才报告中位 `xref`，否则相对量 unavailable，绝不补选另一段。

逐行保留原始 RGB、投影曲线、全部原始/平滑10/50/90上升/下降交点与平台平段。
复用已冻结算子：Gaussian7、sigma1.5px、reflect3；原始方向余弦≥.7、编码对比≥8、
对比≥5×两端稳健spread（下限1）、清晰支持≥12px、次峰/主峰≤.8、10/50/90各唯一
上升交点、过渡原始反向步长≤1、位置不确定度`.25+主峰tie跨度×.25pt`且≤1pt。
原生AX与Android实际前景边界取共同并集并扩2pt；任何扫描/平台相交就失败。缺少原始
前景测量的元素保持遮挡未知，不把容器空白当作已证实材料。多像、弱边、遮挡与源相位/
before/context差异必须逐行逐条件保留，不跨失败连接轨迹。

只在完整连续合格支持上用固定 `h=4pt` 差分：`s=[x(y+4)−x(y−4)]/8`，
`q=[x(y+4)−2x(y)+x(y−4)]/16`，表观有符号曲率 `κ=q/(1+s²)^(3/2)`；
两端及中间所有行必须合格，不越遮挡求导。原始绝对位置与中心相对位置都报告，
左侧外偏为`−Δx`、右侧为`+Δx`，不把预期方向作为选峰或通过条件。
不确定度按绝对边界相加传播，不假定高斯独立，不对轨迹拟合或额外平滑。

颜色轨道在解码前锁定：raw encoded 与有合法最高优先级声明的 normalized sRGB 分开，
无有效颜色依据就不可归一化，不能挑结果好看的轨道。完整显示、实际 Window 和 rejected
display保持独立；被拒图不能作primary，Window只在测量的原始世界坐标内分析，不拼接/
填充成显示图。缺原始repeat/before/after、源相位不明或层级不同必须标记，不把旧fixture
声明为干净反演实验。先检查来源、前景、颜色和固定边界的可辨识性，再由root决定是否
执行现有历史像素分析；本准备不运行分析、不更新runtime或公开库。
